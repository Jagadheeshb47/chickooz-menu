First time? Set up saving
  1. On github.com tap your photo, then Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name it "menu". Repository access: Only select repositories, choose your menu repo. Permissions: Repository permissions, Contents: Read and write.
  3. Tap Generate token and copy it. The first time you tap Save menu, paste it. It stays only on this phone. Never share it.
